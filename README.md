# HALink

一个轻量的 macOS 菜单栏工具，用键盘控制 Home Assistant。

- 填写本地 HA 地址和长期访问令牌。
- 搜索并添加设备，为每个动作自定义全局快捷键。
- 支持单独的 F1–F20，包括 F17，也支持组合键。
- 点击菜单栏图标，打开设备控制小窗，查看状态并执行动作。
- 添加设备和快捷键后自动生效；设备旁的开关直接控制设备电源。
- 在设置中管理 HA 连接和开机启动。
- 支持添加多台服务器、设置自定义名称，并从服务器列表进入设定和切换连接。
- Token 存在系统钥匙串；设备和快捷键保存在本机，按服务器分别管理。

支持灯、开关、风扇、窗帘、空调电源、媒体播放器、场景、脚本和按钮。可选动作取决于 HA 已提供的功能。

## 安装与使用

打开 DMG，把 HALink 拖入“应用程序”，再打开 App。需要 Apple Silicon Mac 和 macOS 26 或更新系统。

在“设置 → Home Assistant 连接”中点击“添加新服务器”，填写名称、HA 地址（例如 `http://192.168.1.10:8123`）和 Token，点击“保存并连接”。Token 可在 HA 的“个人资料 → 安全 → 长期访问令牌”中创建。点击已有服务器右侧箭头，可修改名称和连接信息，或切换到这台服务器。

在“我的设备”中点击“添加设备”，选择设备和动作，录入快捷键后保存。关闭窗口后 App 会留在菜单栏中；退出 App 后快捷键停止。

## 本地构建

使用支持 Swift 6.2 或更新版本的 Xcode 工具链：

```sh
./script/build_and_run.sh
```

可在 Xcode 中打开 `Package.swift`。无第三方依赖。
